# Licence inventory — English Shadowing v1.0.0

The shipped extension contains **no third-party JavaScript**. All code in
`src/` is the project's own; the build tools below run only on the developer's
machine and are not distributed. The data files that *are* shipped carry their
own licences and attribution, listed first.

## Shipped data and attribution

| Component | Where | Licence | Attribution shown in the product |
|---|---|---|---|
| CMUdict (CMU Pronouncing Dictionary) | `public/dict/dict.json`, `public/dict/dict.bin` (~2.1 MB) | BSD-style 2-clause ("Carnegie Mellon University") | Credits, Settings tab |
| Wiktionary definitions, via freedictionaryapi.com | Fetched at runtime, cached locally | Wiktionary content is CC BY-SA 4.0; freedictionaryapi.com is a free keyless service | Credits, Settings tab |
| YouGlish | Outbound link only (`https://youglish.com/pronounce/…`); nothing is downloaded or cached | YouGlish's own terms | "Powered by YouGlish.com" next to the button |
| Google Translate | Outbound link only ("Translate" in the pop-up) | Google's terms | n/a (plain link) |
| Web Speech API (`speechSynthesis`) and `SpeechRecognition` | Browser built-in; no library | — | — |
| Google Chrome speech service | Optional, only while word checking is on | Google's terms | Privacy note beside the Record button |

No CMUdict, Wiktionary, YouGlish, Google or other content is re-licensed or
redistributed as ours; attribution stays visible in **Settings → Credits**.

## Assets

## Notes

- The dictionary API is keyless and sends only the selected word; see
  `PRIVACY.md`.
- If a dependency's licence changes in a future bump, re-check this file before
  shipping. `npm ls --all` and `license-checker` (not a dependency) can both
  regenerate the transitive list.
